# Тестовая 360° Панорама

## Описание
Тестовый проект для проверки работы Pannellum с одной панорамой (`test.jpg`).

## Структура
- `index.html` - Основной файл viewer'а
- `test.jpg` - Твоя тестовая панорама (замени на свою!)
- `README.md` - Этот файл

## Запуск локально
1. Открой `index.html` в браузере напрямую (двойной клик)
2. Или запусти локальный сервер:
   ```bash
   python -m http.server 8000
