# Кухня-гостиная | ЖК Акватория

Интерактивный панорамный тур по кухне-гостиной квартиры в ЖК "Акватория". Содержит 4 ракурса с возможностью навигации между ними.

## 📸 Панорамы

| # | Ракурс | Файл | Размер |
|---|--------|------|--------|
| 1 | Ракурс 1 | `360_001_0000.jpg` | ~9.5 MB |
| 2 | Ракурс 2 | `360_002_0000.jpg` | ~9.8 MB |
| 3 | Ракурс 3 | `360_003_0000.jpg` | ~9.7 MB |
| 4 | Ракурс 4 | `360_004_0000.jpg` | ~8.4 MB |

## 🎮 Навигация

- **Стрелки ◀▶** — переключение между ракурсами
- **Меню ☰** — быстрый выбор нужного ракурса
- **Хотпоинты на панораме** — кликабельные стрелки перехода
