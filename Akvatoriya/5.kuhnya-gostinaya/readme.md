# Кухня-гостиная | ЖК Акватория

Интерактивный панорамный тур по кухне-гостиной квартиры в ЖК "Акватория". Содержит 4 ракурса с возможностью навигации между ними.

## 📸 Панорамы (WebP)

| # | Ракурс | Описание              | Файл                  | Размер |
|---|--------|-----------------------|-----------------------|--------|
| 1 | Ракурс 1 | Общий вид кухни       | `360_001_0000.webp`   | ~0.7 MB |
| 2 | Ракурс 2 | Вид на гостиную       | `360_002_0000.webp`   | ~1.0 MB |
| 3 | Ракурс 3 | Вид на окно           | `360_003_0000.webp`   | ~1.1 MB |
| 4 | Ракурс 4 | Общий план            | `360_004_0000.webp`   | ~0.6 MB |

## 🎮 Навигация

- **Стрелки ◀▶** — переключение между ракурсами
- **Меню ☰** — быстрый выбор нужного ракурса
- **Хотпоинты на панораме** — кликабельные стрелки перехода

## 📌 Особенности

- Единый HTML файл со всеми 4 панорамами (WebP формат для быстрой загрузки)
- Плавная навигация между ракурсами
- Адаптивный дизайн для мобильных устройств
- Прелоадер при загрузке
- Подсказка с инструкцией при старте
