# 360° Тур по квартире Дзержинский

Интерактивный панорамный тур со переходами между комнатами.

## 🏠 Комнаты

| Помещение | Описание |
|-----------|----------|
| Прихожая | Центральный хаб - переходы во все комнаты |
| Кухня-гостиная | Кухня с обеденной зоной и диваном |
| Детская | Спальня для взрослого ребёнка |
| Ванная | Ванна, раковина, стиральная машина |

## 🔗 Открыть тур

[🌐 Открыть 360° Тур](https://viztemplate.github.io/360-panorama-tour/Dserjinsky/360-tour/index.html)

```

└── vanaya.jpg         ← Ванная
```

## 🎯 Переходы

Все комнаты соединены через прихожую:
- **Прихожая** → Кухня, Детская, Ванная
- **Кухня** → Прихожая
- **Детская** → Прихожая
- **Ванная** → Прихожая
